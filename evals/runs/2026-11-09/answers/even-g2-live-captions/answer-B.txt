# Live captions on Even G2: structure and glasses-side code

I read the Even Hub example plugin in the smart-glasses-skills repo and adapted it below. It has only run in Even's simulator, not on real G2 hardware, so check the numbers (line width, 120 ms debounce) on the glasses.

## Structure

```
phone mic ─► VAD ─► streaming STT (partials + finals) ─► relay server ─► G2 plugin (WebView in Even app)
                    keys stay on server                  WebSocket        fit lines → textContainerUpgrade
```

- **Capture on the phone, not the glasses.** G2 can open its own mic, but it's tuned for the wearer's mouth. The phone, placed near the other person, hears them better.
- **Use a streaming STT that returns partial results.** Deepgram, AssemblyAI, Speechmatics and similar services all do. A batch API that answers after the sentence ends will feel broken. Keep the API key on your server.
- **Normalise every provider to one event shape**, `{seq, text, final}`. `text` is the whole sentence so far, not a delta.
- **Run the plugin as a pure display client.** On Even Hub the plugin is a WebView. It receives events and draws lines, and it doesn't touch the mic.
- **Use WebSocket first, with a polling fallback.** Some Even app WebViews on iOS reportedly fail the WebSocket handshake while `fetch` works. After two failed attempts, poll `GET /latest` every 0.5–1 s and keep retrying the socket slowly.
- **Reconnect when the plugin returns to the foreground**, and have the server replay the last lines.
- **Latency budget:** first words in about 1 s, finals in about 2 s. The G2 display path costs roughly 120 ms of debounce plus about 80 ms per container write. Timestamp each stage before tuning anything.

The repo has a runnable server (`--demo`, `--browser-mic`, `--stt deepgram`) in `examples/live-captions/server`. I'd start from that rather than writing the relay yourself.

## Glasses side

**1. Caption state.** Partials replace, finals commit. `seq` guards against replays after a reconnect.

```ts
export type Caption = { seq: number; text: string; final: boolean }
export type CaptionState = { finals: string[]; partial: string; seq: number }

export function apply(st: CaptionState, m: Caption | { type: 'clear' }): boolean {
  if ('type' in m) { st.finals = []; st.partial = ''; return true }
  if (m.seq <= st.seq) return false
  st.seq = m.seq
  if (!m.final) { st.partial = m.text; return true }
  st.partial = ''
  if (m.text) st.finals = [...st.finals.slice(-29), m.text]
  return true
}
```

**2. Line fitting.** Wrap each final once and cache it, so committed lines never jump. Re-wrap only the partial. `measure` should be real font metrics, for example `getTextWidth` from `@evenrealities/pretext`.

```ts
export const LINE_H = 27
export const utf8Len = (s: string) => new TextEncoder().encode(s).length

const seg = new Intl.Segmenter(undefined, { granularity: 'word' })

export function wrap(text: string, maxWidth: number, measure: (s: string) => number): string[] {
  const out: string[] = []
  let line = ''
  const push = () => { if (line.trim()) out.push(line.trim()); line = '' }
  for (const { segment: p } of seg.segment(text.replace(/\s+/g, ' ').trim())) {
    if (!line && !p.trim()) continue
    if (measure((line + p).trimEnd()) <= maxWidth) { line += p; continue }
    if (!p.trim()) { push(); continue }
    push()
    if (measure(p) <= maxWidth) { line = p; continue }
    for (const ch of p) { if (line && measure(line + ch) > maxWidth) push(); line += ch }
  }
  push()
  return out
}

export class Fitter {
  private cache = new Map<string, string[]>() // wrapped finals, keyed by text
  constructor(private width: number, private measure: (s: string) => number,
              private histLines: number, private liveLines: number) {}

  frame(st: CaptionState): { history: string; live: string } {
    const w = this.width - 6 // slack for rounding differences vs. the firmware renderer
    const committed = st.finals.flatMap(f => {
      let l = this.cache.get(f)
      if (!l) this.cache.set(f, (l = wrap(f, w, this.measure)))
      return l
    })
    const live = wrap(st.partial, w, this.measure)
    if (live.length > this.liveLines) {                 // long partial: show its tail
      committed.push(...live.slice(0, -this.liveLines))
    }
    return {
      history: committed.slice(-this.histLines).join('\n'),
      live: live.slice(-this.liveLines).join('\n'),
    }
  }
}
```

**3. Display driver.** This is the part that needs to be right on G2. It follows the example's `glasses.ts`, trimmed to the essentials.

```ts
import {
  CreateStartUpPageContainer, RebuildPageContainer, StartUpPageCreateResult,
  TextContainerProperty, TextContainerUpgrade, type EvenAppBridge,
} from '@evenrealities/even_hub_sdk'

type Box = { id: number; name: string; x: number; y: number; w: number; h: number; pad: number; color: number; capture?: boolean }
// Fixed layout: one-line status (event capture), dim history, bright live sentence.
export const STATUS:  Box = { id: 1, name: 'status',  x: 0, y: 0,   w: 576, h: 32,  pad: 2, color: 2, capture: true }
export const HISTORY: Box = { id: 2, name: 'history', x: 0, y: 32,  w: 576, h: 140, pad: 4, color: 2 }
export const LIVE:    Box = { id: 3, name: 'live',    x: 0, y: 172, w: 576, h: 116, pad: 4, color: 4 }
const BOXES = [STATUS, HISTORY, LIVE]
export type Frame = Record<string, string>

export class Glasses {
  private want: Frame | null = null
  private shown = new Map<string, string>()
  private pageUp = false
  private startupCalled = false
  private running = false
  private timer?: ReturnType<typeof setTimeout>

  constructor(private bridge: EvenAppBridge) {}

  show(f: Frame) {                       // call as often as you like; newest frame wins
    this.want = f
    clearTimeout(this.timer)
    this.timer = setTimeout(() => void this.run(), 120)   // BLE can't keep up with per-token writes
  }

  private async run() {
    if (this.running) return             // never issue concurrent bridge calls
    this.running = true
    try {
      while (this.want) {
        const f = this.want; this.want = null
        await this.apply(f)
      }
    } finally { this.running = false }
  }

  private page(f: Frame) {
    const textObject = BOXES.map(b => new TextContainerProperty({
      xPosition: b.x, yPosition: b.y, width: b.w, height: b.h,
      borderWidth: 0, borderColor: 0, borderRadius: 0, paddingLength: b.pad,
      containerID: b.id, containerName: b.name,
      isEventCapture: b.capture ? 1 : 0, textColor: b.color,
      content: (f[b.name] || '').slice(0, 999),
    }))
    return { containerTotalNum: textObject.length, textObject }
  }

  private async apply(f: Frame) {
    if (!this.pageUp) {
      let ok = false
      if (!this.startupCalled) {
        this.startupCalled = true        // create may only be called once; latch the call, not the success
        ok = (await this.bridge.createStartUpPageContainer(new CreateStartUpPageContainer(this.page(f))))
             === StartUpPageCreateResult.success
      }
      if (!ok) ok = await this.bridge.rebuildPageContainer(new RebuildPageContainer(this.page(f)))
      if (ok) {
        this.pageUp = true
        this.shown = new Map(BOXES.map(b => [b.name, f[b.name] || '']))
      } else {
        setTimeout(() => this.show(f), 1500)  // glasses unreachable: retry (use real backoff in production)
      }
      return
    }
    for (const b of BOXES) {
      const next = f[b.name] || '', prev = this.shown.get(b.name) ?? ''
      if (next === prev) continue        // only send containers that changed
      const ok = await this.bridge.textContainerUpgrade(new TextContainerUpgrade({
        containerID: b.id, containerName: b.name,        // must match create, or the call silently does nothing
        content: next.slice(0, 1999),
        contentOffset: 0,
        contentLength: Math.max(utf8Len(prev), utf8Len(next)), // replace the whole old text (UTF-8 bytes)
      }))
      if (!ok) { this.pageUp = false; this.want ??= f; return }  // page lost: rebuild on the next pass
      this.shown.set(b.name, next)
    }
  }
}
const utf8Len = (s: string) => new TextEncoder().encode(s).length
```

**4. Wiring.** `waitForEvenAppBridge` is the SDK's bridge entry point. Check its exact name against your installed `@evenrealities/even_hub_sdk` version.

```ts
import { waitForEvenAppBridge } from '@evenrealities/even_hub_sdk'
import { getTextWidth } from '@evenrealities/pretext'

const bridge = await waitForEvenAppBridge()
const glasses = new Glasses(bridge)
const fitter = new Fitter(576 - 8, getTextWidth, /*hist*/ 4, /*live*/ 3)
const st: CaptionState = { finals: [], partial: '', seq: -1 }

function onMessage(m: any) {
  if (m.type === 'caption' || m.type === 'clear') {
    if (apply(st, m.type === 'clear' ? { type: 'clear' } : m)) {
      glasses.show({ status: 'LIVE', ...fitter.frame(st) })
    }
  }
}

let fails = 0
function connect(url: string) {
  const ws = new WebSocket(url)
  ws.onopen = () => { fails = 0 }
  ws.onmessage = e => onMessage(JSON.parse(e.data))
  ws.onclose = ws.onerror = () => {
    if (++fails >= 2) startPolling(url)        // WebSocket blocked: fall back to GET /latest
    setTimeout(() => connect(url), Math.min(30000, 1000 * 2 ** fails))
  }
}
```

Two things to add yourself:

- A `startPolling` loop that calls `fetch('/latest')` every 0.5–1 s and feeds the results into `onMessage`.
- Reconnect and `glasses.show(...)` again when the plugin comes back to the foreground.

## G2 pitfalls

- **One write at a time.** Parallel `textContainerUpgrade` calls are reported to break the BLE link. The `running` flag and single loop above prevent that.
- **Keep the capture container to one line.** If its text overflows, the firmware scrolls it and swallows swipes. That's why `status` is a one-line container.
- **Missing glyphs vanish silently.** The G2 font covers Latin, Cyrillic, Greek and CJK. Arabic, Hebrew, Thai and Indic scripts get dropped with no error, so strip them and warn the wearer.
- **`n` newlines make `n + 1` lines.** Padding an empty container with `\n` makes it overflow and show a scrollbar.
- **Smart formatting can change what you show.** Deepgram's `smart_format` turned "four o'clock" into "04:00" in the skill's test. Decide on number and time formatting for the display, not only for the transcript.
- **Long silences can end the STT session.** Deepgram closes after about 10 s without audio unless you send `KeepAlive`. Restart sessions on sentence boundaries.

## Privacy

You're transcribing someone who didn't install your app. Show a visible indicator, check recording-consent law where you'll use it, don't store audio, and delete transcripts after the session.
