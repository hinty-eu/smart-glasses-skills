# Smart Glasses Skills

This repository contains agent skills for building apps on smart glasses. If your agent does not load skills
automatically, read the skill files directly:

- `skills/smart-glasses/SKILL.md` - start here: choose a target, show text on any glasses, input, audio, testing, publishing.
- `skills/smart-glasses-live-captions/SKILL.md` - live captions, translation and real-time hints.
- `skills/smart-glasses-rokid/SKILL.md` - Rokid Glasses from an Android phone (CXR-L).
- `skills/smart-glasses-vuzix/SKILL.md` - Vuzix Z100 with the Ultralite SDK.

Each skill keeps its details in its own `references/` folder.
